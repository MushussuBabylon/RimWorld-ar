## 🚀 طريقة التثبيت (Installation)

**الشرح:**
1. **حمل المود**
2. **انسخ مجلد `Arabic_MOD` وألصقه داخل مجلد اللعبة الرئيسي (`Mods`)**
   

### 1. نسخة Steam 🎮
المسار الافتراضي:
`C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods`

### 2. نسخة GOG 📂
المسار الافتراضي:
`C:\GOG Games\RimWorld\Mods`
