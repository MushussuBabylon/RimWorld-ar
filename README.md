## طريقة التثبيت

1. حمّل [أحدث إصدار](https://github.com/MushussuBabylon/RimWorld-ar/releases/tag/latest-release).
2. فك ضغط `ArabicSupport.zip` مباشرة داخل مجلد اللعبة الرئيسي `RimWorld`.
3. فعّل مود `ArabicSupport` من قائمة المودات داخل اللعبة (يتطلب مود `Harmony`). ويمكنك أيضاً تفعيل `Arabic Auto Translation` لترجمة المودات الأخرى.
4. اختر اللغة العربية من قائمة اختيار اللغة داخل اللعبة.

### المسارات الافتراضية

**Steam:**
`C:\Program Files (x86)\Steam\steamapps\common\RimWorld`

**GOG:**
`C:\GOG Games\RimWorld`

# 🇬🇧 RimWorld Arabic Translation

A comprehensive Arabic translation for **RimWorld**, covering the base game and all official DLCs.

`ArabicSupport` combines the translation with Arabic language support, including connected letters, custom fonts, text formatting, and line wrapping.

**ArabicSupport Mod:** [GitHub Repository](https://github.com/MushussuBabylon/ArabicSupport)  
**Download Translation:** [Download Latest Release](https://github.com/MushussuBabylon/RimWorld-ar/releases/tag/latest-release)

## Installation

1. Download the [latest release](https://github.com/MushussuBabylon/RimWorld-ar/releases/tag/latest-release).
2. Extract `ArabicSupport.zip` directly into your main `RimWorld` game directory.
3. Enable `ArabicSupport` from the in-game Mods menu (requires `Harmony`). You can also enable `Arabic Auto Translation` to translate other mods.
4. Select Arabic from the in-game language selection menu.

### Default Installation Paths

**Steam:**
`C:\Program Files (x86)\Steam\steamapps\common\RimWorld`

**GOG:**
`C:\GOG Games\RimWorld`

## Contributions and Bug Reports

To help improve the translation, open an Issue or submit a Pull Request with:

- **Original Text:** The text you want to change.
- **Suggested Translation:** Your proposed alternative.
- **Screenshot:** An in-game image showing the text.

Suggestions are reviewed and suitable changes are included in future updates. New releases are automatically built and published every Friday or manually when needed.
