# RimWorld Arabic terminology glossary  (mandatory, machine-readable)
#
# Source of truth for the glossary component of the Arabic support (Source/ArabicAutoTranslation/Arabic/Core/Glossary).
# Every "English -> Arabic" pair of the supplied RimWorld Terminology Glossary is copied here verbatim; the plural,
# feminine and matching attributes were added so the terms can be enforced. Attributes that are NOT part of the
# supplied glossary (derived plurals, aliases, matching mode) are listed in "derived=" so a maintainer can tell them
# apart from the approved terms and review them.
#
# FILE FORMAT (UTF-8, one entry per line):
#   English [ / alias ... ] | Arabic | attribute | attribute=value ...
# Section lines "[Name]" or "[Name | package.id]" give the DLC scope of the entries that follow; "Standardized"
# applies to every DLC. Lines starting with # and blank lines are ignored.
#
# ATTRIBUTES
#   mode=any|whole|start   where the term may be enforced: anywhere (default), only when it is the complete text
#                          (a label), or only at the start of the text.
#   cs                     only when written with a capital first letter (names that are also common words).
#   adj                    adjective: it follows its noun in Arabic, so it is enforced only as a complete label.
#   guard                  noun that is also an English verb: not enforced where it is used as a verb.
#   pl= fem= fpl=          Arabic plural / feminine / feminine plural form.
#   def= indef=            explicit definite / indefinite Arabic form (otherwise derived for single words).
#   enpl=a;b               extra English plural spellings.
#   mod=id;id              only for text of these mods (package ids).   key=text   only when the text key contains it.
#   id=                    explicit entry id (needed when two entries share the same English text).
#   derived=a,b            attributes that were derived by rule and are not in the supplied glossary.
#
# Changing any entry changes the glossary version (a content hash), which invalidates exactly the cached
# translations whose source text contains an affected term.
